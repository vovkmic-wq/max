# Проверки публичной версии

Проверено 11 октября 2026 года в Windows с Python 3.12.

- Полный запуск pytest: 204 теста, без ошибок и пропусков.
- После добавления двух сценариев и исправления маршрута списка профилей повторены
  затронутые проверки: итоговый набор включает 206 уникальных успешно пройденных тестов.
- Ruff проверил `src`, `tests`, `scripts` и узлы ComfyUI; ошибок нет.
- `node --check` проверил JavaScript панели.
- Установка зависимостей прошла `pip check`.
- Проверены две публикации в разные каналы через тестовый адаптер, отдельные темы,
  часовые пояса, расписания, права доступа, остановка одного канала при ошибке,
  инвалидирование подборки после смены темы и восстановление в другом каталоге.
- Рабочая установка отдельно подтвердила загрузку закреплённой локальной модели,
  доступ к реальному каналу и работу встроенного планировщика. Эта авторизация
  остаётся локальной и не передаётся вместе с репозиторием.

Для комментариев отдельно проверена эквивалентность AST: добавление русских
пояснений не изменило выражения, строки или порядок выполнения Python-кода.

Перед публикацией проверены файлы и история Git на совпадения с действующими
локальными ключами. Значения ключей не публикуются. `.env.local`, конфигурация
рабочей установки, база, браузерный профиль и зашифрованные архивы исключены.

Реальный перенос в новую Linux VM не выполнялся. Инструкции установки Windows/Linux
и тест восстановления в другом каталоге находятся в
[руководстве по переносу](MULTICHANNEL_PORTABILITY.md). На новой машине нужен
повторный вход в MAX, проверка подключений и явное включение расписаний.

Старые отчёты в `docs/research` относятся к соответствующим этапам разработки;
их меньшие числа тестов не являются результатом текущего полного набора.
