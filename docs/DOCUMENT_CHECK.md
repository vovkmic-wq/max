Schema проверки выполнены встроенным Test-Json в PowerShell 7.6.5 с указанными JSON Schema Draft 2020-12 схемами; проверка ссылок и manifests — bundled Python без установки дополнительных пакетов.

## Отрицательные проверки

Для темы: неизвестное поле, неизвестный режим, время 25:99, отрицательный бюджет, отсутствие theme, выходной язык кроме ru. Для источников: неизвестный тип, интервал ниже 60 секунд, включённый непроверенный источник, file URL, лишнее поле с секретом, включённый канал без внешнего идентификатора.

Смысловые правила — заполнение темы, допустимая зона времени, уникальность id, право доступа к реальной площадке и соблюдение бюджета во время работы — должны быть реализованы и испытаны разработчиком. JSON Schema не доказывает эти условия сама по себе.
