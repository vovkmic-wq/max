# 30 бесплатных площадок для изображений

Pixabay опрашивается напрямую; остальные площадки индексируются через [Openverse API](https://api.openverse.org/v1/). Это 30 разных сайтов с отдельными записями в каталоге, но 2 API-пути доступа. Из Openverse принимаются только CC0, Public Domain Mark и CC BY при наличии ссылки на лицензию и страницу оригинала. Для CC BY обязателен автор.

За сутки расписание опрашивает все 29 площадок Openverse по очереди, примерно по пять на четырёхчасовой интервал. Наличие сайта в реестре не означает, что каждое его изображение разрешено к копированию: право проверяется по лицензии конкретного файла. Некоторые сайты могут не дать результатов по теме `digital art`; нулевой результат не подменяется картинками без подтверждённых прав. Просмотры и лайки берутся только там, где API их предоставляет.
