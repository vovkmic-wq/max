# Генерация нейровидео в VM 109

VM 109 (llama-inference, 10.20.30.95) имеет проброшенную AMD Radeon Bonaire [1002:665c] с 4 ГиБ VRAM. Гостевая ОС использует amdgpu и Mesa RADV 25.2.8. Vulkan распознаёт эту карту; аппаратные fp16 и bf16 недоступны. GPU уже обслуживает LLM, занимающую около 2.8 ГиБ VRAM.

Для видеогенерации установлен отдельный runtime stable-diffusion.cpp с Vulkan. Он размещён в /opt/max-video и работает под пользователем maxvideo. Исходная модель Wan 2.1 T2V 1.3B взята из Comfy-Org и преобразована локально в Q5_0; UMT5 XXL использует Q4_K_M, VAE — оригинальные safetensors. Пути, версии и SHA-256 исходных весов зафиксированы в [wan-models.json](../deployment/comfy/wan-models.json).

## Связка с агентом

Агент MAX обращается к прежнему ComfyUI в контейнере 111. Workflow содержит узел MaxWanVM109, который передаёт ограниченное задание в native API stable-diffusion.cpp на VM 109. Там диффузия выполняется через Vulkan, а текстовый энкодер и VAE используют CPU. Возвращённый AVI передаётся штатному SaveVideo в ComfyUI и сохраняется как MP4.

Сторонние узлы ComfyUI остаются отключёнными; исключение сделано только для написанного в этом проекте MaxWanVM109. Платные partner nodes отключены. API VM 109 слушает порт 8190; отдельное правило nftables допускает только localhost и адрес ComfyUI 10.20.30.82. Существующие службы llama.cpp и model-router не изменяются установщиком.

Служба max-wan ограничена 2 CPU, 8 ГиБ RAM и приоритетом Nice=10. Бюджет управляемых GPU буферов — 0.65 ГиБ. Драйвер и сторонние процессы не входят в этот бюджет; при изменении нагрузки на LLM доступная память может стать недостаточной. Генерация в таком случае может завершиться ошибкой. Одновременную нагрузку на обе модели следует оценивать отдельно.

## Workflow

[API workflow](../config/comfy/wan21-vm109.example.json) связывает prompt, negative prompt, seed и число кадров. Начальный профиль: 192×192, 9 кадров, 8 fps, 8 шагов. Узел допускает размеры 128–256 с шагом 16, до 33 кадров и до 30 шагов. Число кадров округляется вверх до 4*n+1, минимум 9. Это короткий профиль для проверки на ограниченном оборудовании, а не обещание качества или скорости полноценного 480p видео.

Workflow зарегистрирован в работающем агенте 7 октября 2026 года; агент перезапущен и сообщает video.state=available. Для повторной регистрации в другом экземпляре:

```powershell
.venv\Scripts\python.exe scripts\configure_comfy.py `
  --workflow data/incoming/wan21-vm109.json --url http://10.20.30.82:8188 `
  --positive-node 1 --negative-node 2 --seed-node 1 `
  --frames-node 1 --frames-input frames --fps 8 --local-zero-cost
```

После регистрации требуется перезапуск агента. Структура графа фиксируется SHA-256; модель может менять только связанные поля. Публикация MAX остаётся отдельно от одобрения генерации.

## Надёжность

ComfyUI сохраняет обычные prompt_id. Узел дополнительно сохраняет состояние отправки и remote job ID в temp/max-vm109. Потерянный ответ POST, исчезнувшее задание после перезапуска native сервера и истёкшая история не разрешают повторную отправку. Готовый файл проверяется по SHA-256. Повтор с теми же параметрами использует сохранённый результат. После ошибки без remote ID нужен разбор исхода; смена seed означает новое задание и не служит автоматическим обходом неизвестного результата.

Native сервер хранит историю в памяти и очищает завершённые задания по TTL. Узел сохраняет полученный результат локально. Для переноса активных генераций требуется сохранить temp/max-vm109 отдельно: стандартная резервная копия агента этот каталог ComfyUI не включает.

## Повторная установка

В выделенной VM использовать [install-vm109-wan.sh](../deployment/comfy/install-vm109-wan.sh) вместе с файлами той же папки. Установщик отказывается работать на Proxmox host, проверяет бинарный архив и веса, создаёт Q5_0 из исходной модели и устанавливает отдельные службы. GPU драйвер заранее должен предоставлять рабочий Vulkan. Службы и сетевые адреса в примере относятся к этой VM и контейнеру.

Для ComfyUI скопировать [nodes_vm109](../deployment/comfy/nodes_vm109/__init__.py) в custom_nodes/MaxWanVM109 и добавить к прежнему ExecStart параметры --disable-partner-nodes --whitelist-custom-nodes MaxWanVM109 при сохранении --disable-all-custom-nodes. Перезапустить только службу ComfyUI.

## Проверки

Живая генерация выполнена: 192×192, 9 кадров, 8 fps, 8 шагов, MP4 без звука, 1.13 секунды по метаданным, 22645 байт. Native job занял 241.91 секунды, включая 52.28 секунды диффузии на GPU и 96.43 секунды декодирования VAE на CPU. Наблюдалась загрузка GPU 100%; пиковая RAM службы — 4538933248 байт (около 4.23 ГиБ). SHA-256 ролика: 1e4635a315119fd6a416bc09857fae93042bfe3ef7a43dcb5ef2dd4f7fb72f63. [Машинный отчёт](research/wan-vm109-verification.json).

Это настоящий результат Wan, но качество минимального профиля низкое: изображение сильно размыто, короткий фрагмент не предназначен для публикации. QA проверил полное декодирование и отсутствие чёрных кадров; такая проверка не оценивает художественное качество. Полноценные 480p видео на этом оборудовании не проверялись.

Подтверждены отправка, poll и download через настоящий адаптер агента. Для проверки адаптера повторно использован сохранённый результат той же генерации, без второго вычислительного задания. Затем результат импортирован в отдельный тестовый видеопроект, смонтирован и сохранён как черновик для review. Автоматическая публикация не выполнялась.

Живая проверка выявила ошибку QA коротких файлов: точка 90% округлённой длительности могла оказаться позже последнего кадра при низком fps. Исправлен выбор последнего декодированного кадра; масштабирование перед reverse ограничивает память, используемую для этой операции. Добавлен регрессионный тест с 9 кадрами при 8 fps.

Полный итоговый прогон проекта: **142 passed, 0 failed, 0 skipped**; 60.15 секунды. [JUnit](research/wan-vm109-tests.xml). Ruff пройден. Включены 10 проверок связки и проверка QA короткого видео. Предупреждение Starlette/HTTPX сохраняется. Полная совместная нагрузка на LLM и видеогенерацию не принималась.

После генерации служба max-wan перезапущена: PID сменился с 2585 на 2789, состояние active/running, автозапуск enabled. Native API снова сообщает поддержку vid_gen и доступен из ComfyUI. Службы llama-server@qwen35-9b и model-router остались active. Черновик тестового проекта находится в review_pending.
