# Реализация гибридного варианта

Версия 0.2.0 от 6 октября 2026 года. Добавлены собственные сценарии и раскадровка через OpenCode или ручной ввод, один генератор ComfyUI, постоянные сценовые задания, монтаж и подборки разрешённых роликов. Результат обоих потоков проходит одобрение редактора.

## Поставка

Новые модули: comfy.py, hybrid.py и video_tools.py. Миграция 0002 добавляет video_projects, video_scenes, video_assets и material_media. В панели появились видеопроекты, найденные видеовложения, просмотр результатов, одобрение генерации, импорт сцен, монтаж и остановка проекта. Сценарий из OpenCode проверяется строгим контрактом; собственную творческую подпись разрешает серверная связь видеопроекта с черновиком.

Сохранены ограничения dry_run и человеческое одобрение публикации. Изменение backend или workflow после одобрения очереди блокирует отправку. Неизвестный исход запроса ComfyUI не повторяется автоматически: используется request_id и сверка истории и очереди. Расходы резервируются до отправки; бюджет проверяется по проекту и каналу.

Монтаж нормализует размер и частоту кадров, сохраняет доступный звук, объединяет сцены, проверяет MP4 и декодирование. Проверки чёрных кадров и зависаний дают предупреждения редактору. Кадровые отпечатки обнаруживают повторно закодированные ролики и направляют похожие результаты на review. Метод эвристический и требует дальнейшей калибровки на реальной подборке.

Источники разделяются через purpose. Подборка скачивает видео только из разрешённого пула при подтверждённых правах и разрешении полного репоста в теме. Происхождение и ссылка сохраняются. Полный перенос состояния принимает старую схему резервирования с пустыми новыми таблицами.

## Проверки

Полный прогон: **131 passed, 0 failed, 0 skipped**, 145.36 секунды. [JUnit](research/hybrid-tests.xml), [покрытие](research/hybrid-coverage.json). Ruff, Python compileall, JavaScript syntax check и pip check пройдены. Wheel версии 0.2.0 собран.

В тестах: строгий сценарий, бюджеты до запроса, подпись workflow, потерянный ответ без повтора, восстановление prompt_id, стандартный SaveVideo images выход, контрактные генерация и скачивание, реальный монтаж FFmpeg, проверка чёрных кадров, визуальные отпечатки, подготовка разрешённой подборки, авторизация API, редактирование собственного черновика и восстановление после сбоя монтажа. Прежние проверки проекта также сохранены.

Техническая демонстрация запускается scripts/hybrid_demo.py в отдельном data/hybrid-demo. Она создаёт две технические сцены FFmpeg и проходит монтаж и review; внешние запросы, нейросетевой генератор и MAX отправка не используются.

## Живые зависимости

Обновление 7 октября: установлен Wan 2.1 1.3B в VM 109 с Vulkan, workflow подключён к работающему агенту. Настоящая генерация, сохранение MP4 и подготовка черновика прошли проверку. Исправлена QA коротких роликов; итоговый прогон — 142 теста. [Подробный отчёт](WAN_VM109.md). Ниже сохранён контекст первичной установки; генерация полномасштабного видео не принималась.

ComfyUI 0.39.0 установлен на Proxmox в отдельном CPU контейнере 111. Настоящие API, выполнение графа EmptyImage → SaveImage, получение PNG и восстановление после перезапуска службы проверены. [Отчёт проверки](COMFY_PROXMOX.md). Видеомодель и экспортированный API workflow пока отсутствуют, поэтому нейросетевая генерация остаётся неподтверждённой. Внешний платный генератор не выбран и расходы не включены. Видеозадания адаптера проверены контрактными ответами, а операции монтажа — настоящими файлами и FFmpeg.

API OpenCode доступен; настоящая генерация текста в текущей проверке не выполнялась. Предыдущая проверка зафиксировала недоступность выбранного провайдера. Приватный тестовый канал MAX создан, профиль test добавлен в настройки; бота у владельца пока нет, поэтому подключение и автоматические публикации ожидают его создания и получения токена. Реальные источники требуют настройки владельцем. Работа PostgreSQL и перенос на второй физический хост не принимались. Проверенные компоненты не обозначаются как production готовность всего проекта.

## Запуск

Использовать [руководство гибридного канала](HYBRID.md). Для существующей установки выполнить alembic upgrade head, затем перезапустить сервис. Для генератора зарегистрировать свой проверенный workflow через scripts/configure_comfy.py; этот шаг сохраняет настройку и не запускает генерацию. Можно начать с импорта разрешённых готовых сцен и роликов, затем подключить генерацию на подходящей машине.
