# Реализация и испытания агента нейровидео

Версия 0.1.0, 6 октября 2026 года. Реализация находится в src/max_channel_agent, зависимости установлены в проектную .venv, OpenCode 2.0.17 установлен отдельно в локальный node_modules. Исходный проект C:\script\20260926-opencode использован для чтения версии и адреса выбранного локального провайдера; его файлы не изменялись.

## Реализованные возможности

- Корневой TOPIC.md со схемой, семантической проверкой, уникальностью идентификаторов, версиями и блокировкой отправки при повреждении.
- Тема «короткие видео, созданные нейросетями», русский язык, рубрики, предел 60 секунд и исходный dry_run.
- PostgreSQL совместимые SQLAlchemy модели и SQLite профиль, постоянные jobs, inbox, outbox, cursor, audit, бюджеты, поколения модели и редакционные ревизии.
- RSS, HTML с CSS профилем, обработка разрешённых Telegram и MAX событий, чтение доступного источника MAX через API.
- Точные повторы, кандидаты смысловых событий и межъязыковая проверка через OpenCode; обновлённое содержимое исходника сохраняется отдельно.
- OpenCode V2 сессии с запретом инструментов, Basic авторизацией, отменой и удалением; классификация, перевод, черновик, проверка, оформление и план продвижения.
- Контроль источников, чисел, длины, языка, evidence, ревизии, календаря, режима, бюджета и паузы.
- Подключение MAX, адаптер отправки, неизвестный результат, сверка, исправление собственной публикации и её история.
- Русская панель с owner/editor/viewer, просмотром источников, задач, черновиков, публикаций, кампаний и аудита.
- Импорт MP4, проверка FFmpeg, SHA256 медиа, права, новая ревизия, загрузка видео во вложение MAX.
- Планы продвижения, коммерческая отметка, рекламная доля, ручные метрики с происхождением; никакие платежи и закупки рекламы автоматически не выполняются.
- Шифрованная копия, проверка целостности, восстановление только в пустую базу, пауза после восстановления и переустановка в другом корне.

## Проверки

Окончательные результаты pytest находятся в [tests.xml](research/tests.xml), покрытие — в [coverage.json](research/coverage.json). Ruff, compileall и pip check пройдены. Wheel содержит Python модули и статические файлы панели. [HTTP smoke](research/http-smoke.json) подтверждает 200 для панели, live, ready и трёх защищённых API запросов с корректным локальным доступом.

Итоговый прогон: **106 passed, 0 failed, 0 skipped**, 34.93 секунды. Покрытие Python кода — **77.75 процента** (отображение coverage округляет до 78 процентов). Осталось одно предупреждение совместимости Starlette TestClient и HTTPX; оно не является результатом живой интеграции и не скрывает пропущенные тесты.

В набор входят конфигурации и ошибки JSON, SSRF и DNS pinning, RSS/HTML и 304, дедупликация, перевод чисел, точная ревизия одобрения, календарь, пауза, dry_run, запрет повторной отправки при unknown и после падения, классификация ошибок MAX, роли и webhook, конкурентные reservations и выдача задания одному worker, шифрование, восстановление, проверка MP4 и полный цикл RSS → review → тестовая публикация. Внешние адаптеры в этих сценариях используют фикстуры.

Перенос проверен установкой wheel и pinned зависимостей в новый venv внутри .test-state/relocated. Импорт произошёл из site-packages новой среды; конфигурация и база созданы относительно нового корня. [Отчёт](research/relocation-smoke.json). Это проверка другого каталога на той же Windows машине. Вторая физическая машина и Linux в данной сессии не проверялись.

## Живые зависимости

| Компонент | Подтверждено | Ограничение |
| --- | --- | --- |
| OpenCode | Локальный бинарник 2.0.17, авторизованный API, создание сессии, действующая OpenAPI | Провайдер proxmox/qwen35-4b возвращает 503; настоящего текстового ответа нет |
| MAX | Реализованный HTTP адаптер и контрактные тесты | Токен и тестовый канал не заданы; живых публикаций не выполнялось |
| Источники | RSS/HTML и события проверены фикстурами | Реальный пул источников не выбран и отключён |
| Генерация видео | Импорт готового MP4 и публикационный адаптер | Конкретный генератор не выбран и не реализован; автоматическое создание роликов недоступно |
| PostgreSQL | Компиляция моделей и SQL с SKIP LOCKED, Compose профиль | Настоящий сервер и его транзакции не тестировались |
| Перенос | Новый каталог, отдельный venv, wheel, новая база | Второй хост и целевые RPO/RTO пока не приняты |

Состояние проекта — LOCAL_MVP_TESTED. Это не OFFLINE_ACCEPTED всего исходного ТЗ и не PRODUCTION_ACCEPTED. [OpenCode smoke](research/opencode-live-smoke.json) фиксирует конкретную недоступность провайдера вместо фиктивного успеха.

## Требования и следующие проверки

FR01, FR03, FR06, FR11, FR12, FR15, FR19 и FR20 проверены для локального профиля. FR02, FR04, FR05, FR07–FR10 и FR13–FR14 имеют реализацию и локальные сценарии, но требуют указанных live или редакционных проверок. FR16–FR18 реализованы в части планирования, ручного учёта, коммерческой проверки и бюджета; атрибуция кампаний, автоматические внешние размещения и платежи остаются расширениями.

Полная приёмка смысловой точности на 100 размеченных материалах, обработка всех медиа источников и альбомов, автоматическое создание канала, MTProto, retention очистка исторического сырья, внешние уведомления, production нагрузка и физический перенос остаются следующими задачами. Эти возможности не считаются проверенными текущими тестами.

Для запуска использовать [RUNNING_AGENT.md](RUNNING_AGENT.md). Сначала восстановить доступ к модели, выбрать источники и подключить тестовый MAX канал. Затем принять реальную генерацию и отправку, после этого менять режим публикации для рабочего канала.
